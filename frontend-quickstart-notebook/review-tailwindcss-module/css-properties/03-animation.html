10. fill-mode（动画前后状态）

点击"播放动画"按钮查看效果，注意对比每个方块动画前后的状态变化

none
前后都不保持
结束后回到初始状态

forwards
结束后保持最后一帧
（红色、大尺寸）

backwards
开始前应用第一帧
（绿色）

both
开始前第一帧
结束后保持最后一帧
