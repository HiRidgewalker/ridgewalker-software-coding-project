# Go 基础语法学习项目

这是一个 Go 语言基础语法的学习项目，通过大量示例代码全面讲解 Go 语言的核心语法知识。

## 项目结构

| 章节 | 内容 |
|------|------|
| `go-basic-01` | 变量声明、作用域、匿名变量 |
| `go-basic-02` | 基本数据类型：整型、浮点型、字符串、布尔类型 |
| `go-basic-03` | 指针和常量 |
| `go-basic-04` | 数组、切片、Map（字典） |
| `go-basic-05` | 条件控制：if、for、switch、goto |
| `go-basic-06` | 函数：返回值、参数传递、匿名函数、闭包、defer |
| `go-basic-07` | 结构体与方法 |
| `go-basic-08` | 接口定义与实现 |
| `go-basic-09` | Goroutine 与 Channel（并发编程） |
| `go-basic-10` | 网络编程：TCP/UDP Socket、HTTP 服务与客户端 |
| `go-basic-practice` | 练习题 |

## 主要内容

- **变量与类型**：变量声明、数据类型、类型转换
- **流程控制**：条件语句、循环语句、跳转语句
- **函数**：函数定义、参数传递、返回值、闭包、错误处理
- **数据结构**：数组、切片、Map 的使用
- **面向对象**：结构体、方法、接口
- **并发编程**：Goroutine、Channel、互斥锁、读写锁
- **网络编程**：TCP/UDP 通信、HTTP 服务开发

## 运行示例

```bash
cd go-basic-01
go run 01_go_开始.go
```
