## Project Overview

This is a PyTorch study project containing introductory examples and experiments with PyTorch. The codebase is minimal and consists of basic Python scripts and Jupyter notebooks for learning PyTorch concepts.

## Project Structure

- `hello.py` - Basic PyTorch setup script that imports torch and prints the version
- `hello.ipynb` - Jupyter notebook with simple Python examples for testing the environment

## Development Environment

This project uses PyTorch as the primary deep learning framework. The project appears to be in early stages with minimal structure.

## Running Code

To run the Python script:
```bash
python hello.py
```

To work with the Jupyter notebook:
```bash
jupyter notebook hello.ipynb
```

or if using Jupyter Lab:
```bash
jupyter lab hello.ipynb
```
